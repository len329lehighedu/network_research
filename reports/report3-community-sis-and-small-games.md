# Report 3 — Community SIS and small contact games

**Communication log:** Third results email, PDF pp. 12–17.

The community experiment uses 20 networks of 200 people with eight communities of 25. Each world starts with 10 infected people. Each of the 12 scenarios has 50 epidemic runs per world over 84 days at β = 0.085 and γ = 0.20. Whole keeps communities intact, Random randomly splits people into two groups, and Even splits each community evenly. Each Rotating schedule has an On–Off control matched on active edge-days.

Whole-community rotation reduces mean infection relative to its matched On–Off control in both switching schedules. It also retains more contacts and has more infection than the other Rotating splits. The weekly advantage for Whole remains after conditioning on infection still being present and in the deterministic approximation. This leaves room for both nonlinear growth and stochastic fadeout.

## Reproduction

[`beta0085_20w50r.npz`](../network_sis/data/beta0085_20w50r.npz) stores all 12 trajectory arrays with shape **(world, run, day) = (20, 50, 85)**, one active-contact-day array per scenario with shape **(20,)**, and the model settings. It is a NumPy data archive for scripts, rather than a document to open manually. From the repository root, inspect it with:

```bash
PYTHONPATH=network_sis .venv/bin/python - <<'PY'
from network_communities import load_community_data

paths, contacts, settings = load_community_data(
    "network_sis/data/beta0085_20w50r.npz"
)
print(settings)
print(paths[("whole", "rotating", 7)].shape)
print(contacts[("whole", "rotating", 7)])
PY
```

Recalculate the weekly, survivor, deterministic, and linearized tables **from the saved data and the same seeded worlds**, without rerunning stochastic epidemic trajectories:

```bash
.venv/bin/python network_sis/analyze_weekly_advantage.py \
  network_sis/data/beta0085_20w50r.npz \
  --deterministic --linearized
```

To regenerate all stochastic trajectories from scratch, write to a separate output path so the archived data remains available for comparison:

```bash
.venv/bin/python -u network_sis/network_communities.py \
  --worlds 20 --runs-per-world 50 --beta 0.085 \
  --save-data network_sis/data/reproduced_beta0085_20w50r.npz
```

The early-growth threshold table can be regenerated separately:

```bash
PYTHONPATH=network_sis .venv/bin/python - <<'PY'
from network_communities import (
    print_community_threshold_table,
    run_community_threshold_experiment,
)

print_community_threshold_table(run_community_threshold_experiment(20))
PY
```

The code is in [`network_communities.py`](../network_sis/network_communities.py), [`analyze_weekly_advantage.py`](../network_sis/analyze_weekly_advantage.py), and [`sis_experiment.py`](../network_sis/sis_experiment.py). The tables above use β = 0.085. [Report 4](report4-contact-value-and-network-atlas.md) covers the later contact-value sweep.
