## Payoff and break-even definition

A contact gives each participant value $v$ (the pair receives $2v$). Home cost $c$ excludes contact benefits. Daily welfare charges $L_{\mathrm{day}}$ per infected person-day. The one-day choice model approximates the private cost of a new infection as $L_{\mathrm{day}}/\gamma$. The earlier [payoff note](../pdfs/contact_value_rec.pdf) uses illustrative values. The calculations here use the aligned units requested in the follow-up email.

For Whole versus an alternative split, $v^* = L_{\mathrm{day}}\Delta I/(2\Delta C)$, where $\Delta I$ and $\Delta C$ are the differences in mean infected person-days and active edge-days over the horizon. The two splits schedule equal numbers of people home. The private gain from attending is $c+kv$ less expected private infection cost. Deviation shares use scheduled person-days along SIS paths generated under full compliance.

import os
from pathlib import Path

import numpy as np

    ('0040', .04), ('0050', .05), ('0060', .06),
    ('0070', .07), ('0080', .08), ('0085', .085),

with np.load(data_dir / 'beta0085_20w50r.npz', allow_pickle=False) as data:

    print('|---|---:|')
    for split in ('whole', 'random', 'even'):
        value = data[f'contacts_{split}_rotating_1'].mean()
        print(f'| {split} | {value:,.1f} |')

print('| β | Switch (days) | Whole | Random | Even |')
print('|---:|---:|---:|---:|---:|')
for tag, beta in files:
    with np.load(data_dir / f'beta{tag}_20w50r.npz', allow_pickle=False) as data:
        for switch_days in (1, 7):
            infected = [
                data[f'paths_{split}_rotating_{switch_days}'][:, :, 1:].sum(axis=2).mean()
                for split in ('whole', 'random', 'even')
            ]
            print(f'| {beta:.3f} | {switch_days} | ' +
                  ' | '.join(f'{value:,.2f}' for value in infected) + ' |')

print('| β | Switch (days) | Comparison | Extra infected person-days | Extra active edge-days | v* |')
print('|---:|---:|---|---:|---:|---:|')
for tag, beta in files:
    with np.load(data_dir / f'beta{tag}_20w50r.npz', allow_pickle=False) as data:
        for switch_days in (1, 7):
            for comparison in ('random', 'even'):
                a = data[f'paths_whole_rotating_{switch_days}'][:, :, 1:].sum(axis=2).mean()
                b = data[f'paths_{comparison}_rotating_{switch_days}'][:, :, 1:].sum(axis=2).mean()
                ca = data[f'contacts_whole_rotating_{switch_days}'].mean()
                cb = data[f'contacts_{comparison}_rotating_{switch_days}'].mean()
                value = welfare_break_even_v(data, 'whole', comparison, switch_days, L_day=10)
                print(f'| {beta:.3f} | {switch_days} | Whole–{comparison} | {a-b:,.3f} | {ca-cb:,.1f} | {value:.6f} |')

print('| β | Daily whole–random | Daily whole–even | Weekly whole–random | Weekly whole–even |')

        values = [
            welfare_break_even_v(data, 'whole', comparison, switch_days, L_day=10)
            for switch_days in (1, 7)
            for comparison in ('random', 'even')
        ]
        print(f'| {beta:.3f} | ' + ' | '.join(f'{value:.4f}' for value in values) + ' |')
